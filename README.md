# Лабораторные работы по Python, первый семестр

Вариант 5. Работы № 1–6 запускаются на Python 3 без сторонних пакетов. Для третьей работы нужен `tkinter` и графический рабочий стол.

| Работа | Тема | Запуск |
| --- | --- | --- |
| 1 | ANSI-графика и числовая последовательность | `python3 lab1/main.py` |
| 2 | CSV и XML | `python3 lab2/main.py --author "Rowling"` |
| 3 | Tkinter: генератор учебного ключа | `python3 lab3/main.py` |
| 4 | Задача о рюкзаке | `python3 lab4/main.py` |
| 5 | Регулярные выражения | `python3 lab5/main.py` |
| 6 | Наследование и операторы | `python3 lab6/main.py` |

Исходные наборы данных взяты из [репозиториев заданий ITMOPython-2022](https://github.com/ITMOPython-2022). Генерируемые `references.txt` и `users.csv` появляются при запуске соответствующих программ.
